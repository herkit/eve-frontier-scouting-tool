# Scout Report View

As a user I want to enter a scout report in an effective manner, so that I don't 
spend too much time reporting findings

## Main view
The main view should be a set of 10 clickable buttons with icons representing the
classification and subclassification of the resource. It should have a bottom 
right pill showing the number of each resource. The Sub classification controls 
the main icon, while the classification controls a smaller top left overlay icon.
